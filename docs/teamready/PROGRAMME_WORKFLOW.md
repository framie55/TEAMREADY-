The club produces a ~24-page weekly matchday programme (PDF/graphic pack), reviewed in detail 2026-09-07 (Week 6, 2026/27 season example). This document records what it contains, where each part's data should come from, and a proposed (not yet built) status-tracking system.

## Confirmed data error (2026-09-07)

The "Results This Season" panel (Statistics Centre page) listed the 29 August fixture as **"L, vs Darlington DSRM, 1-2"** — but the real result (verified against `Fixture`) is **a 3-1 win away to Darlington Railway Athletic**. The 1-2 loss to Darlington DSRM actually happened on 5 September, a separate fixture, which didn't appear in that list at all. Two similarly-named opponents (Darlington Railway Athletic vs Darlington DSRM) got crossed. **Root cause not yet traced** — unclear whether this panel is generated live from the app each week or was a one-off manual/AI content-generation slip for that specific week's graphic. *Needs investigation before the next programme is produced*, to know whether this is a recurring risk.

## Proposed status system (not yet built)

Every programme section should be able to say one of: **Ready / Missing information / Awaiting confirmation / Not required this week.** Never invent missing programme information — produce a clear question list for Paul instead. This is a design goal agreed 2026-09-09, not an implemented feature — no such status field currently exists on any programme-related entity.
